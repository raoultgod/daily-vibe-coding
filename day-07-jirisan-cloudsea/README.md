# Day 07 — 운해의 시간 / 지리산 천왕봉

주제: 지리산 천왕봉 일출 무렵 운해 *유사 대기 조건*에 대한 앙상블 합의율.

개요: Open-Meteo의 ECMWF IFS 0.25° 앙상블 예보를 받아, 앞으로 3일의 일출 전 30분~일출 후 3시간 동안 유리한 수직 습도·구름·바람·강수 조건이 동시 발생하는 예보 멤버 비율(%)을 보여줍니다. **실제 운해 발생 확률은 아닙니다.**

## 실행

```sh
cd day-07-jirisan-cloudsea
python3 -m http.server 8077 --bind 127.0.0.1
```

`http://localhost:8077`에서 확인합니다. 인터넷이 필요합니다. 테스트는 `node --test tests/*.test.mjs`.

## 계산 정의

천왕봉 근사 좌표(35.337, 127.733)의 ECMWF IFS 0.25° 앙상블 기본 예보와 50개 멤버를 각각 검사합니다. 한 시간에 멤버별로 다음 조건이 **모두** 충족되면 '운해 유사 조건'으로 정의합니다.

- 700 hPa 상대습도 ≤ 70% (정상 위쪽 공기), 낮은 구름 ≥ 60%, 높은 구름 ≤ 80%
- 지표 부근(모델 격자) 바람 ≤ 30 km/h, 해당 시간 강수 ≤ 0.2 mm

합의율 = 충족한 멤버 / 결측값 없는 멤버 × 100 (반올림). 결측 멤버를 제외하고 유효 분모를 함께 표시합니다. 전부 결측이면 %를 표시하지 않습니다. 수치는 새로고침 때 다시 계산합니다.

**한계:** 기준은 탐색적으로 정했으며 현장 운해 사진·CCTV로 학습·검증·확률 보정하지 않았습니다. 700 hPa는 대략 3 km이고 정상보다 높습니다. 반면 850 hPa는 이 격자의 모델 지면보다 낮아 계산에서 제외했습니다(실제 API의 격자 고도 약 1790m, 지면기압 약 815 hPa, 850 hPa 고도 약 1460m를 확인). 낮은 구름은 정확한 구름 높이가 아니며, 0.25° 격자(약 25 km)는 지리산 계곡과 능선을 구분하지 못합니다. 앙상블 멤버는 독립 관측이 아닙니다. **표시된 %를 ‘실제 운해를 볼 확률’로 해석하면 안 됩니다.** 0%도 가능성이 없다는 뜻이 아닙니다.

실제 확률로 개선하려면 매일 같은 시간·장소에서 운해 유무가 보이는 영상/사진을 누락 없이 라벨링하고, 예보 시점이 맞는 과거 예보와 연결해 시간 순서로 분리된 검증셋에서 신뢰도 도표·Brier 점수 등으로 보정해야 합니다. [국립공원공단 실시간 영상](https://m.knps.or.kr/main/menuctrl.do?menuNo=10)은 실시간 확인용이며, 공개된 과거 일별 운해 라벨 자료는 찾지 못했습니다. 해당 카메라는 점검 중이거나 방향·송출 상태가 변경될 수 있습니다. 산행 안전 판단에 사용하지 마세요.
