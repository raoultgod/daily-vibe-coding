# Day 03 — EDGE / LAB

브라우저에서 동작하는 실시간 **Sobel 윤곽선 카메라**입니다. 어두운 실험실 스타일과 라임색 포인트, 한국어 컨트롤, 모바일 레이아웃을 제공합니다. **외부 런타임 의존성, 빌드, 서버 API, 영상 업로드가 없습니다.**

## 실행

```sh
cd day-03-sobel-camera
python3 -m http.server 8033 --bind 127.0.0.1
```

`http://localhost:8033`을 엽니다. ES 모듈을 사용하므로 `index.html`을 `file://`로 직접 여는 대신 HTTP 서버를 사용하세요.

- **데모 체험**: 카메라/권한 없이 움직이는 도형에 실시간 필터를 적용합니다.
- **카메라 시작 / 정지**: 시작할 때만 권한을 요청하며, 정지 시 모든 트랙을 종료합니다.
- **카메라 선택**: 전면/후면 선호 옵션과 실제 장치 목록을 제공합니다. 전면/후면 장치가 없는 컴퓨터에서는 브라우저가 이용 가능한 카메라를 선택할 수 있습니다. 실행 중 변경하면 기존 카메라를 종료하고 새 장치를 연결합니다.
- **원본 / Sobel / 비교**: 비교는 왼쪽 원본, 오른쪽 Sobel입니다.
- **윤곽선 강도**: 0.0–4.0배. 0에서는 윤곽선이 검게 표시됩니다.
- **좌우 반전**: 원본과 필터 모두에 적용합니다.
- **PNG 저장**: UI 장식을 제외한 현재 캔버스 픽셀을 저장합니다. 정지 후에도 마지막 프레임을 저장할 수 있습니다. 정지된 프레임의 필터를 바꾸려면 소스를 다시 시작하세요.
- **FPS**: 최근 약 1초 동안 실제 렌더링한 프레임 수 / 경과 시간입니다. 카메라는 영상 시간이 바뀔 때만 계산합니다. 브라우저 백그라운드 탭에서는 낮아질 수 있습니다.

## 카메라 보안과 개인정보

카메라 API는 **HTTPS 또는 localhost**에서 사용해야 합니다. 휴대폰에서 `http://라즈베리파이-IP:8033`로 접속하면 데모는 가능하지만 카메라는 브라우저 보안 정책상 차단됩니다. 휴대폰 자체의 localhost는 라즈베리파이가 아닙니다. 원격 기기에서 카메라를 사용하려면 HTTPS로 제공하세요.

영상/사진/장치 ID를 서버에 보내거나 저장하지 않습니다. 분석, 외부 CDN, 외부 폰트, 쿠키도 없습니다. 사진 저장은 사용자가 누를 때만 이루어집니다. 브라우저 다운로드 정책에 따라 저장 위치 선택 또는 이미지 미리보기가 나타날 수 있습니다.

권한 거부, 카메라 없음, 다른 앱의 장치 점유, 보안 컨텍스트 오류를 한국어로 안내합니다. 권한 창이 열린 상태에서 정지/데모 전환을 눌러도 이후 도착한 스트림의 트랙을 즉시 정리합니다. 앱이 브라우저의 권한 창 자체를 닫을 수는 없습니다. 페이지를 떠날 때(`pagehide`)도 트랙을 종료합니다. 장치가 빠지거나 트랙이 종료되면 상태를 안내합니다.

## 필터 구현

- WebGL 1 fragment shader에서 휘도 `0.299R + 0.587G + 0.114B`를 구합니다.
- 3×3 Sobel X/Y 커널을 적용하고 `sqrt(Gx² + Gy²) × 강도`를 0–1로 제한합니다.
- 텍스처 가장자리 샘플은 clamp-to-edge 처리합니다.
- WebGL 출력은 최대 1280×720이며, 화면 비율을 유지합니다.
- WebGL 미지원/초기화 실패/컨텍스트 손실 시 Canvas 2D CPU 필터로 전환합니다. CPU 출력은 최대 480×360으로 제한해 부하를 줄입니다. 성능은 기기에 따라 다릅니다.
- `?cpu`로 CPU 경로를 강제로 시험할 수 있습니다.
- 별도 화면 밖 GPU 캔버스에서 렌더링한 뒤 표시 캔버스로 복사하므로 PNG 저장이 안정적이고 GPU 장애 시 같은 UI에서 CPU로 전환할 수 있습니다.

## Netlify 호환 구조 (배포는 수행하지 않음)

이 디렉터리 자체가 완성된 정적 사이트입니다. 별도 패키지 설치/빌드 명령이 없습니다. 저장소 연결 시 이 디렉터리를 base directory로 지정하고 publish directory는 `.`으로 설정하면 됩니다. `netlify.toml`에는 보안 헤더, 카메라 정책, `.mjs` MIME 타입이 포함됩니다. 모노레포 최상위가 아니라 **이 폴더를 게시 루트로** 사용하세요.

## 파일

```text
index.html           한국어 UI, 접근성 레이블
style.css            반응형 다크 테마
app.js               데모/카메라/입력/UI/FPS/PNG
camera.mjs           취소 가능한 카메라 세션 수명 관리
renderer.mjs         WebGL Sobel + CPU 폴백
filter.mjs           독립적인 CPU Sobel 함수
netlify.toml         빌드 없는 정적 호스팅 설정
 tests/
  filter.test.mjs    Sobel 실제 픽셀 단위 테스트
  camera.test.mjs    늦게 도착한 권한 응답 정리 테스트
  browser.cjs        데모/컨트롤/다운로드/반응형 브라우저 테스트
  integration.cjs    GPU/CPU 픽셀 및 카메라 수명 통합 테스트
```

## 테스트

Node.js 내장 테스트 러너만으로 실행:

```sh
node --test tests/*.test.mjs
```

브라우저 테스트는 **개발용 Playwright와 Chromium이 이미 설치된 환경**에서 실행합니다. 앱 런타임에는 필요하지 않습니다. 위 로컬 서버를 먼저 실행하세요.

```sh
# Playwright가 일반 모듈 경로에 설치돼 있으면 환경 변수 생략 가능
PLAYWRIGHT_PATH=/absolute/path/to/node_modules/playwright node tests/browser.cjs
PLAYWRIGHT_PATH=/absolute/path/to/node_modules/playwright node tests/integration.cjs
# 다른 로컬 포트는 TEST_URL=http://localhost:포트 로 지정
```

테스트는 기존 Chromium 전체 실행 파일을 사용하며 headless-shell 추가 다운로드는 요구하지 않습니다. 테스트용 SwiftShader와 가상 카메라 옵션은 실제 앱 코드에는 포함되지 않습니다. 화면 캡처는 `tests/desktop.png`, `tests/mobile.png`에 로컬 생성되며 Git에서는 제외합니다.

### 실제 검증 범위

- Node 단위 테스트 2개 통과: 수직 경계/평탄 영역 Sobel, 취소 후 늦게 도착한 스트림 종료.
- Chromium 데모 애니메이션, FPS, 모드 전환, 강도, 반전, PNG 다운로드, 정지, 모바일 가로 넘침 없음, 페이지 JS 오류 없음.
- 브라우저에서 WebGL/CPU 출력과 CPU Sobel 참조 픽셀 비교: 시험 패턴의 최대 오차 **0/255**. 0 강도/좌우 반전도 검사.
- 가상 카메라 시작, 실행 중 장치 전환 시 기존 트랙 종료, pagehide 시 전체 트랙 종료.
- 권한 거부/장치 없음/장치 점유 오류 메시지, 대기 중 권한 요청 취소, CPU 데모 확인.
- WebGL 컨텍스트 손실 후 CPU 전환, 보안 컨텍스트/카메라 API 미지원 안내 분기 검사.

물리 카메라/실제 iOS Safari 기기에서의 검증과 Netlify 원격 배포 검증은 수행하지 않았습니다. 소프트웨어 WebGL 테스트는 GPU 계산의 정확성을 검증하지만 실제 기기의 하드웨어 가속 성능을 보장하지는 않습니다.
