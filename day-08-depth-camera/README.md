# Day 08 — DEPTH / Camera Lab

카메라 장면을 Depth Anything V2 Small 모델로 분석해 상대적인 깊이를 색으로 보여주는 브라우저 앱입니다. 보라색은 상대적으로 멀고 노란색은 가깝습니다. 각 프레임에서 정규화된 추정치로 **미터 단위 거리나 정확한 측정값이 아닙니다.** 장면과 조명에 따라 달라지므로 안전·거리 측정 용도로 사용하지 마세요.

## 실행

```sh
npm install
npm run dev
```

출력된 localhost 주소 또는 HTTPS에서 열고 **카메라 시작**을 눌러 권한을 허용합니다. 첫 실행에는 Hugging Face의 `onnx-community/depth-anything-v2-small-ONNX` 모델 및 런타임 파일을 다운로드하므로 네트워크와 시간이 필요합니다. 브라우저 캐시 정책에 따라 다음 실행에도 다운로드할 수 있습니다. WebGPU를 먼저 시도하고 지원하지 않거나 초기화/추론이 실패하면 WASM으로 전환합니다. WASM은 기기에 따라 느릴 수 있습니다.

**원본과 비교**를 선택하면 동일한 프레임의 원본과 깊이를 나란히 표시합니다. **이미지 저장**은 현재 화면의 깊이 이미지 또는 비교 이미지를 PNG로 내려받습니다. **정지** 또는 페이지를 떠나면 카메라 트랙을 해제합니다. 마지막 결과는 정지 후에도 저장할 수 있습니다.

## 개인정보

영상 추론은 브라우저에서 수행하고 카메라 프레임을 서버로 전송하지 않습니다. 시작 시 모델과 실행 파일을 다운로드하기 위해 외부 호스트에 접속합니다. 저장은 사용자가 버튼을 누를 때만 이루어집니다. 호스팅 및 모델 제공자의 일반적인 접속 로그는 해당 서비스 정책을 따릅니다.

## Netlify

저장소 루트 연결 시 Base directory를 `day-08-depth-camera`, Build command를 `npm run build`, Publish directory를 `dist`로 설정합니다. `netlify.toml`에 빌드 및 카메라 권한 정책이 포함되어 있습니다. HTTPS 주소에서 카메라 권한을 허용하세요.

## 검증

```sh
npm test
npm run build
```

테스트는 색상 변환, WebGPU 초기화 실패 시 폴백, 카메라 정지 및 권한 대기 중 취소, 기본 UI 요소를 확인합니다. 실제 카메라, GPU, 모바일 브라우저 및 Netlify 배포는 별도로 확인해야 합니다. 모델과 라이브러리의 배포 조건은 각 프로젝트에서 확인하세요.

### 알려진 검증 및 보안 문제

- 자동화된 헤드리스 브라우저에서 합성 카메라 스트림으로 실제 모델을 불러오려고 했지만, 첫 깊이 프레임을 확인하기 전에 브라우저 연결이 끊기거나 응답이 멈췄습니다. 원인은 확인되지 않았으며 실제 추론 성공을 검증하지 못했습니다. 물리 카메라도 검증하지 못했습니다.
- 모델의 fp32 가중치는 약 99 MB이며 실행 중 메모리 사용량은 더 클 수 있습니다. 모델 설정은 별도 ONNX external data 파일을 사용합니다. 기기에 따라 로딩 또는 추론이 느리거나 실패할 수 있습니다.
- `npm audit`은 Transformers 3.8.1의 Node 의존성 `sharp`를 통해 high 2건을 보고합니다. 4.3.2로 시험 업그레이드하면 감사 결과는 0건이고 테스트와 빌드는 통과했지만, 브라우저 추론을 검증하지 못해 호환성을 확인하지 않은 메이저 업그레이드는 적용하지 않았습니다. 배포 전 실제 브라우저 추론을 검증하고 업그레이드를 재평가하세요.
