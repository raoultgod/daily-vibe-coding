# 음 높이 측정

브라우저 마이크로 한 번에 한 음의 높이를 측정하는 정적 페이지입니다. A4 = 440 Hz 기준으로 음 이름, 옥타브, 주파수와 가장 가까운 음과의 차이(센트)를 표시합니다. 외부 라이브러리와 빌드 과정이 없습니다.

## 실행

이 폴더에서 `python3 -m http.server 8000`을 실행하고 같은 기기의 `http://localhost:8000`을 엽니다. 마이크 사용을 허용한 뒤 음을 내세요. 중지를 누르면 마이크 트랙을 종료합니다. 마이크 접근은 HTTPS 또는 localhost 같은 보안 컨텍스트와 브라우저 권한이 필요합니다. 다른 기기에서 일반 HTTP로 접속하면 마이크가 작동하지 않을 수 있습니다.

## Netlify 배포

저장소를 Netlify에 연결하고 다음과 같이 설정합니다.

- Base directory: `day-05-note-detector`
- Build command: 비워 둠
- Publish directory: `.` (base directory 기준)

배포된 HTTPS 주소에서 마이크 권한을 허용하세요. 또는 이 폴더의 내용을 Netlify에 직접 업로드할 수 있습니다.

## 개인정보와 제한

음성은 브라우저 안에서만 분석합니다. 녹음, 저장, 서버 전송은 하지 않습니다. 단일 음을 위한 간단한 검출기로, 여러 음이 동시에 나거나 주변 소음이 크면 결과가 부정확할 수 있습니다. 약 60–1200 Hz 범위를 대상으로 하며, 악기의 배음, 약한 소리, 브라우저/마이크 처리에 따라 옥타브 오류나 미검출이 발생할 수 있습니다. 정밀 튜너를 대신하지 않습니다.

## 테스트

Node.js가 설치되어 있다면 이 폴더에서 `node --test tests/*.test.js`를 실행합니다. 테스트 외에 실제 기기에서 브라우저 마이크 권한과 입력을 확인해야 합니다.
